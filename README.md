# Bomber Fan

Browser-based 3D bomber arena game.

## Play

https://postworkculture.github.io/bomberfan/

## Hosting

The game is hosted with GitHub Pages from the `main` branch. `index.html` is the game. The manifest, service worker, and icon files provide installable/offline PWA support for the hosted version.

## Character assets

The 20 animated fighters use the [Ultimate Monsters](https://quaternius.com/packs/ultimatemonsters.html) pack by Quaternius under CC0 1.0. Bomber Fan ships colour-enhanced texture variants, generated portraits, and a lazy-loaded animated glTF runtime. Full provenance is recorded in `assets/characters/LICENSE.txt`.
